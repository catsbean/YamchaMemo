## 직접 확인 (자동 조작으로 못 보는 것)

- [x] **H-1 창 닫기** (2026-10-03 메인 창·노트 창 모두 확인 — 사본에 친 글, 원래 노트는 밖의 수정 그대로) — Windows 알림창이 떠서 CDP로 누를 수 없다. 개발 빌드(testvault)에서:
  1. Claude에게 "개발 빌드 띄우고 H-1 도우미 켜 줘"라고 한다(도우미가 글자를 치는 순간 그 파일에 한 줄을 덧붙여
     준다 — 3초 안에 메모장으로 고칠 필요 없다). 아무 노트를 열고 글자를 하나 치면 편집기 위에 "외부에서 수정되었습니다" 띠가 뜬다.
  2. **앱 창 맨 위 오른쪽(최소화·최대화 옆)의 ✕**로 닫는다 → "자유노트에 사본으로 남겼습니다" 알림 → 확인 → 창이 닫힌다.
     (편집기 안의 ✕는 "노트 닫기"라, 저장 못 한 글이 있으면 일부러 닫히지 않고 빨간 알림만 뜬다 — 그게 맞는 동작이다.)
     ✅ 2026-10-03 메인 창은 확인함(사본에 친 글, 원래 노트는 밖의 수정 그대로, 확인 뒤 창 닫힘).
  3. 다시 켜서 자유노트에 `제목 (저장 못 한 편집 …)`이 있고 친 글자가 들어 있는지 본다.
  4. 같은 것을 **별도 노트 창**(노트를 새 창으로 연 것)에서도 한 번.
  5. 끝나면 만든 사본 노트를 지운다.
