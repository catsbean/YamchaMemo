## 직접 확인 (자동 조작으로 못 보는 것)

- [ ] **H-1 창 닫기** — Windows 알림창이 떠서 CDP로 누를 수 없다. 개발 빌드(testvault)에서:
  1. 아무 노트를 열고 글자를 친 뒤, 3초 안에 메모장으로 같은 `.md` 파일을 열어 한 줄 덧붙여 저장한다
     → 편집기 위에 "외부에서 수정되었습니다" 띠가 뜬다.
  2. 메인 창 ✕로 닫는다 → "자유노트에 사본으로 남겼습니다" 알림 → 확인 → 창이 닫힌다.
  3. 다시 켜서 자유노트에 `제목 (저장 못 한 편집 …)`이 있고 친 글자가 들어 있는지 본다.
  4. 같은 것을 **별도 노트 창**(노트를 새 창으로 연 것)에서도 한 번.
  5. 끝나면 만든 사본 노트를 지운다.
