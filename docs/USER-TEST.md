# 처음 쓰는 사람의 10분 (8-6)

YamchaMemo를 **한 번도 본 적 없는 사람** 한 명에게 아래 과제를 차례로 주고, 옆에서 지켜보며 적는다.
목표는 "설치 → 저장 위치 → 첫 노트 → 책 한 권 → 검색"까지 막히지 않는가다.

## 진행하는 사람에게

- **설명하지 않는다.** 과제 문장만 읽어 준다. 버튼 이름도, 메뉴 위치도 알려 주지 않는다.
- 상대가 멈추면 **2분은 기다린다.** 그래도 못 하면 "어디를 찾고 있었어요?"만 묻고 적은 뒤 도와준다.
- 소리 내어 생각하게 한다("지금 뭘 찾는지 말하면서 해 주세요").
- 기록은 **어디서 멈췄는지 · 처음 무엇을 눌렀는지 · 무엇을 찾았는지**가 핵심이다. 칭찬·감상은 덜 중요하다.
- 상대의 컴퓨터에서 한다면, 저장 위치는 상대가 고르게 둔다(클라우드든 문서 폴더든).

## 과제 (이 문장 그대로 읽어 준다)

1. 릴리스 페이지에서 앱을 내려받아 설치하고 실행해 주세요. 메모를 저장할 곳을 정해 주세요.
2. "오늘 떠오른 생각"이라는 제목으로 메모를 하나 써 주세요.
3. 요즘 읽는(또는 읽고 싶은) 책 한 권을 책장에 넣고, 마음에 든 문장을 하나 남겨 주세요.
4. 오늘 일지에 할 일을 하나 적고, 그 할 일을 끝낸 것으로 표시해 주세요.
5. 2번에서 쓴 메모를 검색으로 찾아 다시 열어 주세요.

특히 볼 것 (먼저 돌려 본 결과로 짐작되는 곳):
- 설치 경고에서 그만두는가 (릴리스 페이지 맨 위에 넘기는 법을 붙여 두었다)
- 메뉴 "도서리스트"와 화면 제목 "책장", 그리고 "독서기록"을 어떻게 이해하는가 (아래 7)
- 책을 넣자마자 붙는 별 다섯 개를 자기가 매긴 별점으로 오해하는가 (아래 8)

## 먼저 돌려 본 결과 (2026-10-04, Claude)

새 설정·빈 vault의 개발 빌드로 첫 화면부터 과제 2~5를 실제 키 입력(CDP)으로 밟았다. 설치(과제 1)는 개발 빌드라 건너뛰었다.

| # | 어디 | 무엇 | 처리 |
| --- | --- | --- | --- |
| 1 | 첫 화면 | OneDrive가 회사·개인 둘인데 둘 다 "OneDrive — 자동 백업(권장)" — 경로를 읽어야 구분됐다 | 고침: "OneDrive (회사 이름)"·"OneDrive (개인)" |
| 2 | 홈 | 빈 vault의 홈은 0만 늘어선 카드뿐 — 어디부터 할지 안내가 없다 | 고침: 노트가 없을 때만 "처음이세요?" 카드(첫 메모·책 한 권·오늘 일지) |
| 3 | 새 노트 | 제목 칸이 둘(머리 제목칸 + 아래 칸의 "제목"). 아래 쪽을 고치면 파일 이름은 그대로 | 고침: 제목은 머리 칸만 |
| 4 | 새 노트 | 제목에서 Enter → 본문으로 커서가 안 넘어가 다시 눌러야 했다 | 고침 |
| 5 | 새 노트 | 제목칸 안내 문구가 잘려 보였다 | 고침: "제목 (비우면 첫 줄로)" |
| 6 | 책장 | 빈 책장이 "[+ 책 추가]로 시작해 보세요" — 그런 이름의 버튼이 없다(그림 버튼뿐, ＋는 검색 없는 직접 입력) | 고침: 빈 책장 한가운데 "🔍 제목으로 찾아 추가"·"＋ 직접 입력" |
| 7 | 책장 | 메뉴는 "도서리스트", 화면 제목은 "책장" | 사람 시험에서 본다(이름을 바꾸면 쓰던 사람이 헷갈린다) |
| 8 | 책 | 찾아 넣은 책의 서점 평점이 **내 별점 칸**에 들어간다 — "읽고 싶은 책"인데 별 다섯 개 | 사용자에게 묻는다(의도한 동작이었다 — 검색 창 안내에 "평점까지 채워진다") |
| 9 | 검색 | 결과 미리보기에 `## 기록 > [!발췌] …`처럼 마크다운 기호가 그대로 | 고침: 기호를 걷는다 |
| 10 | 왼쪽 메뉴 | 태그 수가 본문의 `#태그`를 세지 않아 태그 화면과 달랐다(1 vs 0) | 고침: 태그 화면과 같은 곳에서 센다 |
| 11 | 책 기록 | **버그** — 책에 기록을 남겨도 왼쪽 메뉴의 독서기록 수가 0으로 남았다 | 고침 |
| 12 | 일지 | 할 일을 하나도 안 만들었는데 "할 일 다 끝냈습니다" | 고침: "없음" |

잘 된 것: 저장 위치 고르기 → vault 만들기, 책 검색(카카오)·표지·소개 자동, 기록 남기기, 오늘 일지 기록, 검색에서 기록 글귀 찾기는 막힘 없이 됐다.

고친 뒤 새 설정(다른 식별자)·빈 vault로 처음부터 한 번 더 밟아 1~6·9~12가 고쳐진 것을 확인했다.
